# Diabetes Prediction using Logistic Regression

## Project Overview

This project implements a Logistic Regression machine-learning model for binary diabetes outcome prediction and deploys the trained model using Streamlit.

The project follows the requirements provided by the institution, including:

- Data Exploration (EDA)
- Feature inspection
- Data types and summary statistics
- Data visualization
- Missing-value handling
- Data preprocessing
- Logistic Regression model building
- Model training
- Model evaluation
- Accuracy
- Precision
- Recall
- F1-score
- ROC-AUC
- ROC curve visualization
- Feature coefficient interpretation
- Streamlit deployment

The institution's assignment specifically requires deployment of the trained Logistic Regression model using Streamlit with user inputs for prediction.
